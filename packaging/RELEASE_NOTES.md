## Release Kit for Windows

**Download `ReleaseKit-windows-x64.zip`, unzip it anywhere, and double-click `ReleaseKit.exe`.** No Python or ffmpeg install needed; ffmpeg is bundled.

Windows may say "Windows protected your PC" the first time because the app isn't code-signed. Click **More info → Run anyway**.

### What's in this version
- New release wizard: music → cover → where it's going → one button
- Drag and drop audio, photos or whole folders anywhere on the window; titles, BPM and key are read from the files' tags
- SL2 integration: browse your SL2 songs and import them, or auto-import every song you star
- Ready-to-release checklist on every release
- Instant preview frames before rendering
- Overnight batch: a loop video plus paste-ready YouTube text for every track in a folder
- Jobs survive closing the app; optional pop-up and sound when a job finishes; disk space check before long renders
- Plain-English error messages
- Cover history, saved defaults for new releases, remembered video settings
- Black-and-green Studio theme (Ember theme still available in Settings)
